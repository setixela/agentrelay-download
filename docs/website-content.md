# Новая версия сайта AgentRelay

Версия концепции: 1 октября 2026. Основана на каталоге продукта для 1.1.5 build 20. Это прототип для обсуждения перед публикацией.

## Позиционирование

**Вайбкодинг для сеньоров.**

**Агенты делают работу. Вы видите всю картину.**

Смысл «для сеньоров» — опытный инженер делегирует реализацию агентам и наблюдает за работой, историей коммитов и интеграцией веток. В основном сценарии агенты сами пишут и коммитят. Ручной staging и создание коммита доступны в продукте, но не задают сюжет страницы.

Английская адаптация: **Vibe coding. Senior mindset.** Далее: **Agents do the work. You see the whole picture.** Это самостоятельная формулировка того же позиционирования, а не буквальный перевод «coding for seniors».

Альтернативы для следующего обсуждения:

- «Вайбкодинг. С инженерным кругозором.» — спокойнее, но менее конкретно.
- «Агенты пишут. Вы видите, как сходится работа.» — точнее объясняет механику, слабее как короткий слоган.
- «Несколько агентов. Одна картина проекта.» — хорошо для пояснения, менее выразительно для главного заголовка.

## Разделы и действия

| Раздел | Что должен понять посетитель | Форма подачи |
| --- | --- | --- |
| Главный экран | Кто работает и какую роль сохраняет инженер | Крупный слоган, скачивание, схема агентов и Git-графа; выбор коммита раскрывает условный diff |
| Поддерживаемые CLI | Используются знакомые локальные инструменты | Названия провайдеров и пояснение отдельной установки |
| Рабочий сценарий | Задачи → агентские коммиты → наблюдение за интеграцией | Три последовательных шага |
| Ветки, активность, код | Можно перейти от общей картины к подробностям | Три переключаемых информативных плейсхолдера |
| Рабочий холст | Агенты, shell и редактор доступны рядом | Схема четырёх окон и короткие пояснения |
| Сохранение сессий | Закрытие приложения не завершает tmux-агентов | Статическая схема и конкретная граница перезапуска |
| MCP | Агент может управлять разрешёнными сессиями | Таблица четырёх инструментов и модель доступа |
| Ежедневные детали | Важные дополнительные инструменты | Компактный список |
| FAQ | Что устанавливать, сколько стоит, где границы | Нативные раскрывающиеся ответы |
| Установка и версия | Как начать и что изменилось в релизе | Скачивание, три шага, версия/время, «Что нового», GitHub Release |

Основное действие — **скачать для macOS**. Вторичное — **посмотреть сценарий**. У первого скачивания находится ссылка **«Что нового в …»**, которая открывает список в разделе версии. Регистрация и формы сбора email не нужны для существующего бесплатного download-процесса. Интерактивные элементы страницы — меню, переключение схем, выбор коммита, FAQ и заметки релиза.

## Плейсхолдеры и будущие материалы

Все демонстрационные данные помечены как условные. Страница не выдаёт схемы за снятый интерфейс приложения. Плейсхолдеры уже объясняют конкретный сценарий; при замене материалом смысл и место подписи сохраняются.

| Плейсхолдер | Содержание будущего материала |
| --- | --- |
| Агенты и Git-граф на первом экране | Реальный пример двух агентских веток, коммитов и слияния; видны CLI, папка проекта и граф |
| Ветки и слияния | Git-панель с выбранным коммитом и его diff |
| Активность | Терминалы и таймлайн с Working/Idle/Done; не изображать Done как автоматическую проверку результата |
| Код | Переход по пути из терминального вывода к файлу; отдельный Git diff |
| Холст | Агенты, shell и редактор рядом; общая отправка запроса |
| Сохранение процессов | Закрытие и повторное открытие приложения с подключением к тем же tmux-процессам |

Автоматических анимаций нет. Переключение схем и коммитов происходит по действию пользователя. На мобильном контент складывается вертикально; без JS все три схемы остаются доступными.

## Источники и актуальность

Истина о возможностях — каталог в исходном репозитории AgentRelay: `docs/product-feature-catalog.md` (исследование 2026-10-01, код `6f59534d9024de7cc51d6c6b72bbd9a9ae466b22`). Страница выбирает наиболее важные для сценария возможности, а не переносит все 353 строки каталога в landing page.

| Материал сайта | Разделы каталога |
| --- | --- |
| CLI, папки, независимые сессии | A–D |
| Холст и composer | E–F |
| Активность | G |
| Терминал, изображения, экспорт | H–I |
| Редактор | J |
| Граф, diff, история, Git, worktrees, baseline | K–N |
| MCP | O |
| Внешний вид и доступность | P |
| Скачивание и обновления | Q |

При развитии продукта сначала обновляется каталог в том же PR, затем нужные тексты в `content/ru.json` и `content/en.json`. Обе страницы генерируются одной командой; разные языки не должны обещать разные возможности.

Истина о текущем релизе — публичный GitHub Release. `update-release-metadata.py` получает заметки именно для версии экспортированного приложения, проверяет время публикации и пересобирает страницы. Несовпадение или пустые заметки останавливают обновление до записи файлов. Перевод RU хранится с конкретным tag; при новом tag устаревший перевод не используется, показывается явно подписанный английский оригинал. После добавления RU-перевода снова запустите сборку.

Важно сохранять: процессы переживают выход из приложения, но не перезагрузку Mac; CLI установлены отдельно; MCP opt-in и не sandbox; worktrees не создаются автоматически; граф отражает Git, а baseline не доказывает авторство; AgentRelay не заявляется автоматическим движком коммитов и слияний.
