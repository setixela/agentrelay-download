Before your first session.

Do agents make commits and merges themselves?

CLI agents can run Git commands under your instructions and their available permissions. AgentRelay shows the graph and changes and provides Git tools. Commit, validation and merge policies remain part of your workflow.

Which agents are bundled?

Launch profiles for Codex, Claude Code, GitHub Copilot CLI, Hermes and Pi are built in. Install and authenticate the CLIs separately. You can add other local commands.

Is it free?

AgentRelay is a free download. AI providers have their own terms and pricing; their subscriptions are not included.

What survives a restart?

Agent tmux processes survive quitting and reconnecting to the app. After a Mac reboot, you need to start them again. Regular Terminal sessions open a fresh shell.

Is agent work isolated?

Sessions have separate processes and working folders, but AgentRelay does not automatically isolate files. Use Git worktrees for separate repository copies. MCP is not a sandbox either.

Which language does the app use?

The application UI is currently in English. This website is available in Russian and English.
