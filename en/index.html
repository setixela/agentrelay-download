Every agent,one canvas.

AgentRelay runs Codex, Claude Code, GitHub Copilot CLI and other CLI agents in real terminals, side by side in one native macOS window. Send one message to several agents at once. Quit the app, and they keep working.

A tidy canvas in one click.

Windows snap to the canvas edges and to each other, and a shared edge resizes both neighbours at once. When you want the whole canvas in order, the toolbar has five arrangements.

#1 codex · agentrelay
#2 claude · site
#3 hermes · docs
#4 copilot · api

Quit the app. Your agents keep working.

Each agent lives in its own tmux session, not inside the window. AgentRelay only attaches to it, so after a restart every card returns to its place and reattaches to the same running process.

tmux is built in. Nothing extra to install: AgentRelay ships its own universal build.

The honest limits. Restarting your Mac ends agent processes; the card offers to start the CLI again. Plain terminal cards open a fresh login shell in the same folder after an app restart.

Built for long, parallel sessions.

With five agents on three branches, you need to see at a glance who is working where, and where the next message will go.

A bar for every window
Every session, terminal and editor gets a button labelled #number client project branch. Click it to bring the window forward, even if it was minimized.
Precise targeting
⌘-click adds an agent to the message targets, and every targeted window lights up on the canvas. Terminals and editors never receive shared messages.
Expand and restore
The title-bar control fills the canvas with one window; a second click restores it. Double-click the title to grow each edge to the nearest neighbour.
An editor next to the agent
Files open in editor windows on the same canvas, right beside the terminal that is changing them.
Any CLI
Add your own agent with a name, executable and arguments. AgentRelay finds CLIs installed with Homebrew, npm, Bun, Cargo, Volta and asdf, and you can point it at any other path.
A folder for every session
Projects live in a local catalog, so a new session opens in the right folder in a couple of clicks.

Three steps to your first agent.

A free, native macOS app. Signed, notarized by Apple, and it keeps itself up to date.

Download for macOS

macOS 14 or later · Apple Silicon and Intel

  1. Download the archive

    AgentRelay-macOS.zip is one universal build for Apple Silicon and Intel.

  2. Move it to Applications

    Unzip the archive and drag AgentRelay into Applications. When a new version ships, the app offers to update itself.

  3. Pick a folder and start an agent

    Click New session, choose a project and a CLI. Install Codex, Claude Code and other agents separately; tmux is already included.
