Every CLI agent,in one window.

AgentRelay is a native macOS terminal where Codex, Claude Code, GitHub Copilot CLI and other agents work side by side, each in its own window on a shared canvas. See who’s still thinking and who’s done, open paths from the output in the editor, and quit the app while the agents keep working.

Paths in the output are clickable

Click a path, a file:// link or an OSC 8 link to open the file in the built-in editor at the exact line and column. The editor window lands on the same canvas, next to the agent. Other files open in their default app.

Drop a screenshot or several files from Finder and they become quoted paths. Spaces in names don’t break anything.

A path bar under every window

Click to copy the working folder, double-click to open a new terminal there. Next to it: copy all terminal text or open it in the editor. For Codex and Claude Code that’s the whole chat from their logs, not just the visible screen.

Your font, your colors

Any monospaced font; ⌘+ and ⌘− resize text in every window at once. Five palette presets, and every color is editable.

Quit the app. Your agents keep working.

Each agent lives in its own tmux session, not inside the window. AgentRelay only attaches to it, so after a restart every card returns to its place and reattaches to the same running process.

The honest limits. Restarting your Mac ends agent processes; the card offers to start the CLI again. Plain terminal cards open a fresh login shell in the same folder after an app restart.

Small things that save time.

With five agents on three branches, you need to find the right window fast and never lose context.

A bar with every window
Every session, terminal and editor gets a button: #number client project branch. Click it to bring the window forward, even if it’s minimized.
Keyboard first
⌃Tab switches windows, ⌘N starts a session, ⌘P finds a file in the project, ⌃⌥1–5 arrange the canvas.
Scrolling and selection
The wheel and trackpad scroll history, not prompt commands. Selection auto-scrolls past the edge and copies exactly what you selected, even in Codex inside tmux.
Any CLI
A name, an executable, arguments and environment variables. AgentRelay finds CLIs installed with Homebrew, npm, Bun, Cargo, Volta and asdf, and asks for the path if it can’t.
Switch CLI or duplicate
Restart a window with another agent or in another folder without losing its place on the canvas. Duplicate opens a new session of the same CLI in the same project.
One prompt, several agents
⌘-click window buttons to pick agents, and Message sends them the same text.

Three steps to your first agent.

A free, native macOS app. Signed, notarized by Apple, and it keeps itself up to date.

Download for macOS

macOS 14 or later · Apple Silicon and Intel

  1. Download the archive

    AgentRelay-macOS.zip is one universal build for Apple Silicon and Intel.

  2. Move it to Applications

    Unzip the archive and drag AgentRelay into Applications. When a new version ships, the app offers to update itself.

  3. Pick a folder and start an agent

    Click New session, choose a project and a CLI. Install Codex, Claude Code and other agents separately; tmux is already included.
