CLI-агенты в tmux работают и после закрытия приложения. VibeVizor is a native macOS workspace. Codex, Claude Code, GitHub Copilot CLI, Pi, Hermes and your own CLIs run side by side on one canvas, with an editor, a Git client, a browser and notes in the same window. CLI agents in tmux keep working after you quit the app.
