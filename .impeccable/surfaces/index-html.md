# Landing page redesign

Mode: Persuade. Audience: senior developers operating AI CLI agents. Primary action: download for macOS. RU and EN. This is a review prototype, not an approved public launch.

## Direction contract

THESIS: Agents implement and commit; the engineer sees the whole branch and execution picture. The first screen pairs this claim with a readable Git graph rather than a typing animation.

OWN-WORLD: A code-review workbench: cobalt ground, ice-white inspection surfaces, dark blue ink, acid-lime primary action. Geologica's substantial geometric forms carry the headline; JetBrains Mono is limited to actual paths and hashes. Rectangular inspection areas and broad page bands replace repeated feature cards.

STORY: Recognize the multi-agent workflow; see commits converging; learn how activity, editor, persistent sessions and optional MCP keep context; download and launch an installed CLI.

FIRST VIEWPORT: Left half has the two-line Russian slogan, workflow promise and macOS download. Right half is an informative placeholder with named agents above a branch graph and selected commit detail. Signature interaction: select a sample commit and inspect its changes; explicit synthetic label.

FORM: Candidate 3, code-review workbench, seed e7360c9a. Grounded list: workspace cockpit; Git rail map; review workbench; execution control room; engineering notebook; pipeline storyboard; Mac desktop index. Jacquard/cloud/collider/fluid/Tanaka challengers declined on audience and clarity; kept disciplines are traceability, restrained annotation, selected-track focus, continuity and compositional economy. Rietveld competitive on canvas organization but weaker on branch-history clarity. Build directly in code because the user specifically requests informative placeholders instead of imagery and animation. Provisional designer choice under the user's request to make a version; not a standing visual preference.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Constraints: preserve the exact signed appcast, updater, current release metadata and download URL; don't suggest AgentRelay automatically commits/merges. No decorative imagery or autoplay animations, fake forms, metrics or testimonials. The original icon remains.
